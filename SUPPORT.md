# Support

Need help with ApiCatcher?

## Before opening a support request

- Read the [README.md](./README.md) for installation and troubleshooting steps.
- Confirm the page is a normal `http://` or `https://` page.
- Reload the extension from `chrome://extensions/` after making changes.

## Where to ask for help

- Open a GitHub issue for bugs or feature requests.
- Use the repository discussions or issue tracker for questions about usage.
- For security-related concerns, follow the instructions in [SECURITY.md](./SECURITY.md).

## Expected response time

Support requests are reviewed on a best-effort basis. For reproducible bugs, the maintainers typically respond as soon as they are able to review the issue and reproduce it locally.
