# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.0.x | ✅ Supported |
| < 1.0.0 | ❌ Unsupported |

## Reporting a vulnerability

Please report security issues privately through GitHub Private Vulnerability Reporting if available for this repository. If you cannot use the GitHub reporting flow, email the maintainer at `188705139+M003aad@users.noreply.github.com` with a description of the issue, affected version, reproduction steps, and any relevant proof-of-concept details.

We ask that you avoid public disclosure until the issue is investigated and, if necessary, patched.

## Response expectations

- Acknowledgement within 5 business days
- Initial triage within 10 business days
- Security fix or mitigation planned or released within 30 days when feasible
- Public disclosure only after the fix is available or a clear remediation path is in place

## Security update process

The project maintainer will evaluate the severity, confirm the root cause, and coordinate a fix in the next compatible release. Security-related changes will be documented in the changelog and release notes when appropriate.
